Lights Out Game

Turn off all the lights to win. Click a square to toggle its state and adjacent squares!

Development Addendum

Process:This game was implemented in JavaScript, and CSS for the structure of every display unit was used, a responsive grid for the game board. The logic of the switching cells guarantees the neighboring cells are influenced and the result is entertaining and exciting puzzle game.

Creative Choices: The grid size was decided to be 6×6 so that the difficulty is moderate, and colors were selected to give an exciting bright ”on” position in yellow and a less conspicuous ”off” position in dark gray. Some modification was made as the increasing gradient background meant that the game will look more attractive.

Challenges: It took many index checks to make sure the toggling logic would not affect out of bound cells. For simplicity and optimality a win-check algorithm was carried out employing a flat array traversal.
