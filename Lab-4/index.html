Addendum: Styling Choices

Font Choices: Due to the need for the letter to look as professional as possible I chose the ‘Georgia’ serif font – it is perfect for resume or CV. It is serious and at the same time still easy to read.

Heading Sizes: In order to feedback and generate a hierarchy of headings, the headings were gradually decreased from h1 until h2. H1 is designated as the main title and its font size is set at 36px to ensure it captures the viewer’s attention The rest of the titles within sections are sized at 28px so the difference between sections is quite noticeable.

Text Size: The main text size is set to 18px, which balances readability with keeping the content concise. It's large enough for clear reading without overwhelming the viewer.

Color Choices: I selected lightgreen for the entire body to establish a professional and sleek appearance.

Margin and Padding: Each section is padded (20px) for adequate amount of space left, and the layout is very uncluttered, so it was clear what content belonged to which section. Margins between the sections (20px) that will help to maintain spaced layout without aggravating the sections with extra density. layout.

HTML Abuse: Compared to the elements of previous paradigms, none of them was misused in terms of styling. Whereas each tag (for instance h1, h2,, p and others) effectively contains its right semantic purpose. There are no HTML tricks used except the pure visual presentation is handled through the CSS.
